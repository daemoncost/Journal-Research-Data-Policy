Description
-----------

This directory contains information extracted from the YAML encoded
files, regularised, summarised and presented as a set of TSV and CSV
[1-3] outputs.

In the "outputs/" directory, the CSV and TSV files conatain the first
line with a time stamp. Below the first line, a regular TSV or CSV
stream follows as specified in the correspinding format descriptions
[1-3]. Strictly speaking, these files should have '.ttsv' and 'tcsv'
extensions, for "time-stamped TSV" and "time-stamped CSV",
correspondingly.

The "all-answers.{csv,tsv}" files contain variable number of columns;
the number of columns, and the position of the selected "correct"
column can be derived from values in "NAnsw" and "IdxCorrect" columns,
respectively. The more detailed explanation of this is provided in the
"doc/column-descriptions/all-answers_columns.tsv" file.

(Re)calculation instructions
----------------------------

Generation of the files in the "outputs/" directory is managed by a
GNU Makefile that has rules to produce each of them. The Makefile
system is made modular – there is one "master" Makefile that does
nothing except reading in the Makelocal* and Makeconfig* files and
letting their rules produce the desired result.

To run the calculations, you simply type the command

	make

This should also update output files if the input files (from the
inputs/ directory) are updated.

To remove all files generated by 'make', use the command:

	make distclean

Thus, to recalculate the data (e.g. in a new environment) one can
issue:

	make distclean
	make

Dependencies
------------

The code should work on any POSIX compatible system with the necessary
programs (GNU Make, yq) installed; at the moment, it was tested on
Linuxmint-20.3 (x86_64) GNU Linux platform.

The prerequisite programs are:

- GNU Make (GNU Make 4.2.1 tested, any 4.* or even 3.* GNU Make should
  work)

  This is installed by default on Linuxmint-20.3; on other systems one
  may need to install extra packages, e.g.:

  - on Debian 12:

	sudo apt-get install make

- The 'yq' YAML parser/filter. Version yq-4.44.3 was used for the
  computation. Can be installed from sources in the archive
  (unfortunately, no Debian package was located as of the time of
  writing this memo)

  Software repository:

	https://github.com/mikefarah/yq

  For the convenience of the users, a compiled binary ELF version of
  the 'yq' for Intel x86_64 in the directory 'bin/x86_64/', and the
  Unix PATH used by the Makefile is set to include this directory, so
  for Intel x86_64 Linux users installation of 'yq' could be skippted
  and the 'yq' part should work out of the box.

- GNU awk, any recent version. Usually comes with most GNU/Linux
  operating systems. Can be installed using commands on Debian-like
  systems:

	sudo apt-get install gawk

- Perl, to drive the programs in the "scripts/" directory. Perl
  v5.30.0 was used for this computation. Can be installed (if not
  already provided by the system):

	sudo apt-get install perl

- Perl modules:

	Encode
	File::Basename
	Text::CSV

  on Debian-based systems, 'Encode' and 'File::Basename' is a part of
  the standard Perl; the remaining one these can be installed from
  standard repositories:

	sudo apt-get install libtext-csv-perl

- Standard Linux/Unix tools: 'rm', 'sed', 'tail', 'date', 'sort',
  'unique'. Come with the operating system; should be compatible with
  GNU tools.
